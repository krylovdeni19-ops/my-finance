# Мой бюджет — PWA для iPhone

## Что умеет первая версия
- Добавление доходов и расходов с датой.
- Автоматический резерв 10% от доходов месяца в фонд отопления.
- Учёт двух фиксированных ежемесячных платежей по кредитам.
- Учёт жилья, ЖКХ, связи и других обязательных платежей.
- Распределение оставшейся суммы по категориям.
- Локальное хранение данных в браузере.
- Экспорт и импорт резервной копии JSON.
- Кэширование для базовой работы офлайн после первого открытия.

## Публикация через GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `my-finance`.
2. Загрузи в корень репозитория все файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`, нажми Save.
6. Дождись публикации и открой выданный GitHub Pages адрес в Safari на iPhone.
7. В Safari нажми «Поделиться» → «На экран Домой» → включи «Открывать как веб-приложение» (если пункт доступен) → «Добавить».

## Важно
- Данные хранятся локально в браузере на устройстве и не синхронизируются между устройствами.
- Перед очисткой Safari или переносом на другое устройство сделай экспорт JSON в Настройках.
- Это прототип планировщика: он не подключается к банку и не проводит платежи.
- Сумма отчисления в фонд отопления рассчитывается как 10% от суммы всех доходов текущего календарного месяца.
- Суммы кредитов и других обязательств резервируются на месяц целиком; при нескольких поступлениях повторно не вычитаются.
