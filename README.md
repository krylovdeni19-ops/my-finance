MY FINANCE v2.1 — мобильное PWA для личного бюджета

Файлы:
- index.html — интерфейс
- app.js — расчёты и логика
- В версии 2.1 добавлено редактирование операций из истории; даты по умолчанию берутся в местном часовом поясе.
- manifest.webmanifest — установка как приложение
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки

Публикация:
1. В репозитории GitHub открой Add file → Upload files.
2. Загрузи все файлы из этой папки в корень репозитория, заменив одноимённые.
3. Нажми Commit changes.
4. GitHub Pages обновится автоматически через несколько минут.
5. В Safari открой https://ВАШ-ЛОГИН.github.io/my-finance/ и обнови страницу.

Важно:
- Учётные записи хранятся локально в браузере на устройстве; облачной синхронизации нет.
- Экспортируйте JSON-копию в Настройках.
- При публикации репозиторий содержит только код, не финансовые записи.
- Версия 2 использует новый формат хранения и не импортирует автоматически старые локальные записи версии 1. Перед переходом сохраните старые данные, если вносили их.
- 10% фонда отопления рассчитывается от доходов выбранного месяца.
- Обязательные платежи задаются в настройках. Фактические траты типа «Кредит / обязательный платёж» уменьшают сумму неисполненного резерва, чтобы не считать их дважды.
