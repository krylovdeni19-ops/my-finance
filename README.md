# MY FINANCE — версия 3.4.0

Мобильное веб-приложение (PWA) для iPhone. Приложение учитывает только доходы и распределение средств — учёта расходов нет.

## Возможности
- Месячный обзор дохода, обязательств, 10% резерва и распределения по категориям.
- Редактирование и удаление поступлений.
- Годовая аналитика с диаграммой и помесячной сводкой.
- Цель финансовой подушки: фактическая расчётная сумма по-прежнему автоматически равна 10% от всех внесённых доходов; цель показывает прогресс, но не меняет расчёт.
- Отдельные цели накоплений: название, целевая сумма, уже накопленная сумма и желаемый срок.
- Экспорт и импорт резервной копии JSON.
- Локальное хранение данных в браузере.

## Перед обновлением
Сделай «Экспорт данных» в действующей версии и сохрани JSON в приложении «Файлы». Не очищай данные Safari и не удаляй PWA.

## Установка
Распакуй архив и загрузи все файлы из него в корень GitHub-репозитория с заменой одноимённых файлов. После публикации открой сайт в Safari. Не загружай ZIP вместо распакованных файлов.

## Совместимость и приватность
Сохранён прежний ключ localStorage `myFinanceData_v2`. Доходы и настройки предыдущей версии должны подхватиться автоматически. Новые поля целей добавляются без сброса старых данных. Данные хранятся локально на устройстве и не синхронизируются с облаком.

## Правила
- 10% каждого дохода направляется в расчёт финансовой подушки.
- Затем вычитаются ежемесячные обязательные платежи.
- Остаток распределяется по категориям, доли которых должны составлять ровно 100%.
- Цели накоплений не уменьшают доступную сумму и не меняют расчёт распределения — это отдельный трекер прогресса.
