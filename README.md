# MY FINANCE — версия 3.0.0

Мобильное веб-приложение для iPhone (PWA). Учитывает поступления и автоматически распределяет доход: 10% в финансовую подушку, затем обязательные платежи, остаток — по категориям. Учёта расходов и истории покупок нет.

## Файлы
- `index.html` — интерфейс приложения
- `styles.css` — адаптивный дизайн
- `app.js` — логика, расчёты и хранение данных
- `manifest.webmanifest` — параметры установки PWA
- `sw.js` — офлайн-кэш
- `icon.svg` — иконка

## Обновление на GitHub Pages
Загрузи все файлы из архива в корень репозитория, заменив одноимённые файлы. Не загружай сам ZIP вместо распакованных файлов. Проверь, что `index.html` лежит непосредственно в корне репозитория.

После публикации открой сайт в Safari. Если отображается старая версия, закрой установленное приложение и открой сайт в Safari; обновление Service Worker может занять несколько секунд.

## Данные
Данные хранятся локально в браузере на устройстве. Облачной синхронизации нет. Перед обновлением или очисткой браузера используй «Экспорт данных» и сохрани JSON-файл в приложение «Файлы».

Приложение использует ключ `myFinanceData_v2`, чтобы попытаться сохранить доходы и настройки предыдущей версии. Старые записи расходов не импортируются и не отображаются.

## Правило распределения
- 10% дохода резервируется в «Финансовую подушку».
- Из оставшейся суммы вычитаются ежемесячные обязательства.
- Остаток распределяется по долям категорий (в сумме строго 100%).

Доли по умолчанию: Продукты 35%, Транспорт 10%, Быт и дом 8%, Здоровье 5%, Одежда и личное 7%, Кафе и развлечения 10%, Свободные деньги 25%.

«Накоплено» в подушке — расчётные 10% от всех внесённых доходов, а не подтверждённый остаток на банковском счёте.
