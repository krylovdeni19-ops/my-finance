# MY FINANCE — восстановленная сборка v3.3.0

Мобильное веб-приложение (PWA) для iPhone. Учитывает доходы и распределяет их: 10% в финансовую подушку, затем обязательные платежи, остаток — по категориям. Учёта расходов нет.

## Что входит
- Месячный обзор доходов и распределения.
- Резерв 10% от каждого внесённого дохода.
- Обязательные ежемесячные платежи: два кредита, жильё, ЖКХ, связь и прочее.
- Настраиваемые категории распределения (сумма долей строго 100%).
- Добавление, изменение и удаление доходов.
- Годовая аналитика: доход за год, средний доход за активный месяц, резерв за год, самый доходный месяц, диаграмма и помесячная сводка.
- Экспорт и импорт резервной копии JSON.
- Локальное хранение в браузере.

## Важно перед обновлением
Сначала открой действующую версию приложения и нажми «Экспорт данных». Сохрани JSON в приложении «Файлы». Не очищай данные Safari и не удаляй установленную PWA.

## Установка / обновление через GitHub Pages
Распакуй архив и загрузи все файлы из папки в корень репозитория, заменив одноимённые файлы. Не загружай ZIP вместо распакованных файлов. После публикации открой сайт в Safari. При необходимости закрой PWA и открой сайт в Safari для обновления кэша.

## Совместимость
Используется прежний ключ localStorage `myFinanceData_v2`, чтобы приложение могло прочитать доходы и настройки из предыдущей сборки. Данные остаются на этом устройстве и не синхронизируются с облаком.

## Расчёт
10% от дохода резервируется в финансовую подушку. Затем вычитаются фиксированные обязательства. Остаток делится по заданным процентам. Значение подушки — расчётная сумма 10% от всех внесённых доходов, а не подтверждённый банковский остаток.

**Версия:** 3.3.0 — восстановленная сборка с годовой аналитикой распределения доходов.
